# Unit 1: Introduction to Big Data Technologies and Data Management

## Overview
This unit introduces the fundamental concepts of big data, including its characteristics, data types, collection processes and associated challenges.

## Learning Activities
- Introduction to big data technologies and data management.
- Exploration of the characteristics of big data.
- Critical evaluation of Internet of Things (IoT) data collection.
- Collaborative Discussion 1: The Data Collection Process.
- Introduction to GitHub e-Portfolio development.
